☁ Sync with Siri

Share your watchlist, offers, and approvals live across both your phones. One-time setup: create a free Firebase project, paste its config + a shared room name. Both of you use the same config + room.

📖 How to get a free Firebase config (2 min)
  1. Go to console.firebase.google.com → Add project (any name) → skip Analytics.
  2. Build → Realtime Database → Create Database → Start in test mode.
  3. Project settings (⚙) → scroll to Your apps → Web (</>) → register → copy the firebaseConfig object.
  4. Paste it above, pick a room name, hit Connect. Send Siri the same config + room name.
Test mode is fine to start; anyone who knows your room name + config can read it, so keep them private. Ask me to add locked-down security rules once it works.

🇹🇭 Check a Thai plot — paste any coord or a Google Maps URL from DOL / listing

📌 How to grab a coord from DOL Landsmaps (dolwebservice)
1. Sign in to landsmaps.dol.go.th with your Thai ID
2. Search the plot by chanote number (โฉนดเลขที่) or navigate on the map to the parcel
3. Once the parcel is highlighted, click any point inside its polygon — DOL shows lat/lng in the info panel at bottom-left
4. Copy that coord and paste here

Or paste the parcel's chanote details directly from the DOL sidebar — coord will be in the panel.
